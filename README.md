Creative frontend portfolio and personal web design brand focused on responsive

Live portfolio: https://19reginab91.github.io/Regina-CraftLay/

## Overview

Regina | CraftLay is my personal frontend portfolio and creative web design
direction. The project was built to present my work, visual thinking and
frontend skills through several different design worlds instead of a single
standard portfolio style.

The idea behind CraftLay is simple: a website should be clear enough to use,
strong enough to remember and thoughtful enough to support real business goals.

## Concept

CraftLay explores the connection between design, structure, emotion and code.

Instead of using only a basic light or dark theme, the portfolio includes
multiple visual directions. Each one shows a different side of interface design,
brand feeling and user experience.

Design worlds include:

- Clear - structured, minimal, sharp and signal-focused
- Violet - emotional, atmospheric and journal-like
- Wild - bold, confident and expressive
- Nude - soft, editorial and calm

Together, these worlds show my ability to adapt visual language while keeping
structure, usability and responsive layout in focus.
